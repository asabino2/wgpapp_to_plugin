# WGPApp → Plugin

This project creates a plugin for WanGP that converts a Deepy-generated `.wgpapp` bundle into a folder ready to be installed as a plugin.

## How to use


1. Start WanGP and open the `WGPApp → Plugin` tab.
2. Provide:
   - the `.wgpapp` file generated by Deepy;
   - the app title (defaults to the title in the `.wgpapp` file);
   - the app description (defaults to the description in the `.wgpapp` file);
   - the destination folder where the plugin will be generated.
3. The plugin extracts the bundle, creates the plugin structure, and saves all content in the chosen folder.
4. Install the result:
   - by copying the generated folder into WanGP's `plugins` subfolder; or
   - by using the GitHub URL in WanGP's plugin manager.

## CLI

You can also convert it from the command line:

```bash
python tools/wgpapp_to_plugin.py "input.wgpapp" "output/folder" --title "My App" --description "Custom description"
```

If `--title` and `--description` are omitted, the values are read from the `.wgpapp` manifest (`app.json`).

The script writes the files to the output folder and populates a `webapp` subfolder with the original bundle files.

## Generated structure

The resulting folder includes:

- `plugin.py`: the WanGP plugin loader;
- `plugin_info.json`: plugin metadata;
- `__init__.py`;
- `webapp/`: extracted contents from the `.wgpapp` bundle (app.json, index.html, scripts, assets, and thumbnails).

## Note

The generated plugin embeds the Deepy bundle `index.html` in an `iframe` and is compatible with WanGP's plugin convention.
